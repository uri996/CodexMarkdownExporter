Codex Markdown Exporter v1.2.1
Windows 64 位便携版使用说明

========================================
一、软件介绍
========================================

Codex Markdown Exporter 是一个本地 Codex 对话导出工具。

支持将 Codex 历史会话导出为 Markdown 文件，保留真实用户 Prompt、助手最终回答及原始对话顺序。

主要功能：

1. 单独导出：选择一个 Codex 会话，导出完整对话。
2. 项目批量导出：选择一个项目，一次性导出该项目的全部符合条件的会话，每个 Session 保存为独立 Markdown。

同时支持 .jsonl 和 .jsonl.zst 格式，包括 Codex 自动压缩的历史会话。

========================================
二、安装与启动
========================================

1. 完整解压 Codex-Markdown-Exporter-v1.2.1-windows-amd64.zip 文件。
2. 双击 Codex-Markdown-Exporter.exe。
3. 在中文菜单中选择需要的功能。

无需安装 Go、Python 或其他开发环境。

菜单操作：

↑ / ↓    选择
Enter    确认
Esc      返回或退出

本软件是 Windows 控制台程序，不是传统图形界面软件。

========================================
三、设置保存目录
========================================

首次使用时，请先选择 Markdown 保存位置。

进入主菜单的「设置默认保存目录」。

可以选择：

1. 输入自定义文件夹的完整路径。
2. 按 F2 选择 EXE 所在目录下的 exports 文件夹。

按 Enter 确认，再按 Y 保存设置。

程序会记住保存目录，后续导出自动使用。

已经保存的目录不会因程序升级而自动改变。

如果使用便携相对目录，移动 EXE 后，exports 目录会跟随新的 EXE 位置。

更改保存目录不会自动移动或删除旧文件。

========================================
四、单独导出
========================================

主菜单选择：

「单独导出一个会话」

从 Session 列表中选择需要导出的对话，按 Enter 确认。

程序会生成一个 Markdown 文件。

支持查看和选择历史会话，包括已压缩的会话。

========================================
五、按项目批量导出
========================================

主菜单选择：

「按项目批量导出」

从项目列表中选择需要导出的项目。

程序会自动导出该项目下符合条件的全部会话。

每个 Session 对应一个独立 Markdown 文件，不会合并成一个文件。

重复批量导出时，已经成功导出的会话默认跳过，不覆盖已有文件。

如果需要重新导出更新后的会话，可选择新的输出目录。

========================================
六、查看导出结果
========================================

导出完成后，程序会显示文件保存位置及处理结果。

O        打开输出文件夹
Enter    返回主菜单
Esc      退出

批量模式会显示成功、跳过和失败的数量。

如果某个会话导出失败，程序会尽量继续处理其他会话，并在结果中报告错误。

========================================
七、命令行使用（可选）
========================================

除主菜单外，也可以通过终端运行：

查看帮助：
Codex-Markdown-Exporter.exe -help

查看版本：
Codex-Markdown-Exporter.exe -version

单独导出：
Codex-Markdown-Exporter.exe -single

项目批量导出：
Codex-Markdown-Exporter.exe -batch

修改默认保存目录：
Codex-Markdown-Exporter.exe -set-output-dir "D:\Codex-Exports"

临时指定保存目录：
Codex-Markdown-Exporter.exe -batch -output-dir "D:\Codex-Exports"

以上路径仅为示例，请替换为自己的目录。

========================================
八、数据安全与注意事项
========================================

- 所有会话处理均在本机进行，不主动向外部 AI 服务上传对话。
- 程序只读访问 Codex 原始会话文件，不删除、修改或重新压缩历史记录。
- 支持已识别的长文本附件及自动上下文清理。
- 无法读取的附件、损坏的会话或未识别的历史格式可能影响导出结果。
- 导出的 Markdown 可能包含个人信息、项目路径、代码或私人 Prompt，请妥善保管。
- 不要将私人导出文件提交到公开 GitHub 仓库。

本程序未进行代码签名。

请从可信来源下载，并按发布页面提供的 SHA256 校验信息核对文件。不要绕过 Windows 安全保护。
